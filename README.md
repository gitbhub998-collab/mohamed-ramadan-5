# Mohamed Ramadan Gamal — Portfolio

Professional portfolio for Mohamed Ramadan Gamal, a Railway Technology student specializing in Mechanical Systems in Egypt. The page presents railway maintenance training, technical skills and a smart automatic train step project.

The site is built with static HTML, CSS and JavaScript. Profile photographs and the hero background are stored in `assets/`; railway project imagery is stored in `assets/projects/`.

## Deploy to Vercel

Import the repository into Vercel using the **Other** framework preset. Leave the build command empty and set the output directory to `.`. The included `vercel.json` contains these settings; no build step or dependencies are required.
